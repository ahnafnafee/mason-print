The first release of Mason Print brings GMU's print queue to a native Android app.

- Upload several documents through Android's file picker or share files from another app.
- Review queued documents and their prices, open PDF previews, and choose copies, colour, and one- or two-sided printing.
- Find printers by building and floor, scan a printer's code, or type its code. Star frequently used printers and return to recent ones.
- Choose your own balance or a departmental cost center, and review recent transaction history.
- Use light or dark themes, with account controls and connection diagnostics built into the app.

Requires Android 8.0 or newer. Install the attached `MasonPrint-1.0.0.apk` to get started.

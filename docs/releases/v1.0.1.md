Frequently used departmental cost centers are easier to reuse, and queue notifications no longer cover the bottom actions.

- Save cost-center shortcuts per account and select them with one tap from either funding picker. Manually entered cost centers are remembered for future sessions, and saved shortcuts can be removed.
- Queue messages appear above the bottom action bar, keeping release controls and totals visible.
- Switching between queue totals and selected-job actions no longer runs a distracting height animation.
